# The Phantasm Press

A physical card driven AI storyteller, that prints onto receipt paper.

Originally made for [The Late Shows](https://thelateshows.org.uk/) 2026.

## TL;DR

A board with places for four cards, a button and ample RGB lighting.
Four decks of cards, each representing an attribute of a story (protagonist, setting, engine, object).
Place four cards onto the board and the button illuminates.
Press the button and an LLM generates a story based on the chosen attributes.
The story is printed on a thermal receipt printer.
